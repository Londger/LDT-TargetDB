**Title:** LDT-TargetDB: A Structure-Guided Covalent Radiopharmaceutical Target Database

**Synopsis:** LDT-TargetDB is the first database specifically designed for covalent radiopharmaceutical target discovery. It integrates surface proteome annotation (SURFY, 2,799 proteins), tumor/normal expression profiling (TCGA + GTEx), 3D structural pocket analysis (AlphaFold + pyKVFinder), and covalent chemistry scoring (PROPKA pKa + FreeSASA accessibility) to systematically prioritize surface protein targets for ligand-directed transfer (LDT) radiopharmaceutical development. The database covers 2,473 ranked surface proteins across 32 cancer types, with an interactive Streamlit web interface. Key novel features include nucleophile-specific scoring (Lys>Cys>Tyr>Ser based on NASA chemistry), multi-dimensional validation (DepMap, HPA, Open Targets, Ensembl conservation, TCGA mutations), and covalent strategy comparison (LDT-NASA vs SuFEx-CTR vs traditional Cys-targeted).
